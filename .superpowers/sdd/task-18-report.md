## Narrow correction

- `scripts/build_benchmark.py` now encodes the JSONL manifest as UTF-8 and writes
  those bytes directly. Windows text-mode newline translation can no longer change
  the generated artifact.
- `.gitattributes` pins the committed benchmark manifest to `text eol=lf`, so a
  fresh Windows checkout preserves the same bytes generated by the script.
- The 30 generated HWPX/PDF artifacts and the manifest content are unchanged.
  Only cross-platform byte materialization is corrected.
- The existing end-to-end determinism test remains the regression test: it builds
  two independent trees and compares all 31 generated hashes with the committed
  fixture tree.
